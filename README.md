# Calendario figli

PWA condivisibile per visualizzare i weekend alternati con i figli.

## Regola
Il weekend 19–20 settembre 2026 è un weekend con i figli. Da lì l'alternanza prosegue ogni 14 giorni.

## Grafica
Solo i sabati e le domeniche con i figli mostrano un cuore rosso.

## Installazione
Aprire il sito in Safari su iPhone → Condividi → Aggiungi alla schermata Home.

Le festività o accordi specifici possono modificare l'alternanza standard.
